# mangaestudio-backend

## Herramientas utilizadas:

Un listado de las herramientas que utilizo actualmente y para apoyar monetariamente en un futuro.

- **Bun:** entorno de ejecución JavaScript.
- **TypeScript:** lenguaje de programación.
- **VSCode:** editor de código.
- **Git:** control de versiones.
- **GitHub:** repositorio remoto (investigar Gitea).
- **PostgresSQL:** base de datos.
- **Dragonfly**: base de datos desde la memoria.
- **BiomeJS:** formateador y corrector de código.
- **Astro.js:** creador de páginas HTML.
- **Docker:** contenedores.
- **Porkbun:** gestor de dominios.
- **Fathom Analitycs:** analíticas (investigar Umami).
- **Cloudflared:** CDN (investigar Bunny.net)
